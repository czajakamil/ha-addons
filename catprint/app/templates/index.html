    🤖 MCP Server (AI Agenci)

    Plik mcp_server.py udostępnia drukarkę jako narzędzia MCP. Agenty (Claude Desktop, Claude Code, własne agenty) mogą drukować bez otwierania przeglądarki. Serwer Flask musi być uruchomiony — MCP woła jego REST API przez HTTP.

    Instalacja
    pip install mcp httpx
# lub razem z resztą zależności:
pip install -r requirements.txt
